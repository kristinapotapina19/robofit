# РобоФит — подбор роботизированных решений с расчётом экономического эффекта

Веб-платформа экспресс-предынвестиционной оценки роботизации. Кейс «Лидеры цифровой трансформации 2026», ФЦ БАС. Команда «Сатипончики».

Пользователь выбирает объект (склад, аэропорт, медучреждение или свой) и операцию, вводит или загружает параметры. Платформа подбирает решения из каталога и объясняет, почему каждое подходит или исключено. Затем она считает парк роботов, CAPEX, OPEX, эффект, окупаемость, ROI и TCO по трём сценариям (без роботизации, покупка, RaaS), показывает чувствительность и what-if и проигрывает смену на 2D-схеме объекта. Имитация на схеме подтверждает расчёт: это та же модель, по которой сервер определил парк. В конце сохраняется проект и выгружается отчёт PDF/Excel.


## Требования

- Python 3.11 или 3.12 (НЕ 3.13+)
- Node.js 18+
- Docker Desktop с WSL2 (для Windows)
- Git

## Быстрый запуск

Нужен Docker с Compose.

```bash
git clone https://github.com/kristinapotapina19/robofit.git
cd robofit
cp .env.example .env    # Windows CMD: copy .env.example .env
docker compose up --build
```

| Что | Адрес |
|---|---|
| Интерфейс | http://localhost:5173 |
| API, Swagger | http://localhost:8000/docs |
| OpenAPI | http://localhost:8000/openapi.json |

Демо-учётки: 
-пользователь `user@demo` / `demo123`
-администратор `admin@demo` / `admin123`
Без входа доступны каталог, подбор, расчёт и отчёт.

Интернет для работы не нужен: каталог и демо-датасеты организатора загружаются из репозитория (п. 4.2.7 ТЗ). Если PostgreSQL недоступна, API переключается на файловое хранилище и продолжает работать.

### Один контейнер (для стенда)

```bash
docker build -t robofit .
docker run -p 8000:8000 robofit        # интерфейс и API на http://localhost:8000
```

## Запуск без Docker

Linux / macOS / WSL
  ```# Backend
  cd backend
  python3 -m venv venv
  source venv/bin/activate
  pip install -r requirements.txt
  DATABASE_URL= uvicorn app.main:app --reload

  # Frontend (в новом окне терминала)
  cd frontend
  npm install
  npm run dev  # → http://localhost:5173
  ```

Windows (CMD)
  ### Backend
  cd backend
  python -m venv venv
  venv\Scripts\activate
  pip install -r requirements.txt
  set DATABASE_URL=uvicorn app.main:app --reload

  ### Frontend (в новом окне CMD)
  cd frontend
  npm install
  npm run dev

### Проверка расчётного ядра и пример отчёта

```bash
cd backend
python scripts/etl.py           # исходные файлы организатора -> data/seed
python scripts/demo_report.py   # расчёт по всем операциям + отчёты в docs/examples
```

## Структура

```
backend/
  app/api/routes.py       REST API: каталог, параметры, подбор, расчёт, отчёты, проекты, админка
  app/core/pipeline.py    сквозной расчёт: потребность -> парк -> сценарии -> чувствительность -> вывод
  app/core/operations.py  профили операций (объём, режим, персонал, маршрут) из data/profiles.json
  app/core/selection.py   правила подбора с вердиктом и причиной, объяснимый рейтинг
  app/core/economics.py   CAPEX, OPEX, эффект, окупаемость, ROI, TCO, RaaS; допущения с источниками
  app/core/simulation.py  посекундная имитация смены, подбор минимального парка
  app/core/params.py      проверка параметров, шаблон и загрузка Excel/CSV
  app/core/report.py      отчёт PDF и Excel
  app/repo.py, app/db/    PostgreSQL (SQLAlchemy) с резервным файловым хранилищем
  app/auth.py             роли, PBKDF2, подписанные токены
  data/raw/               файлы организатора, паспорта эталонных моделей, открытые источники
  data/seed/              результат ETL: каталог, пресеты объектов, отчёт о полноте
  data/profiles.json      профили операций (добавить операцию = добавить запись)
  scripts/etl.py          загрузка и обогащение каталога
frontend/src/
  steps/                  8 шагов мастера
  sim.js, layouts.js      имитация (порт серверной модели) и 2D-схемы объектов
docs/                     архитектура, API, экономическая модель, подбор, данные, руководство
docs/examples/            примеры выгруженных отчётов
```

## Что реализовано

| Функция | Статус |
|---|---|
| Выбор объекта: склад, аэропорт, медучреждение, произвольный объект | полностью |
| Операции: склад — паллеты, отбор G2P, уборка; аэропорт — тягачи, уборка; медучреждение — питание, бельё, медикаменты и пробы; свой объект — транспорт, уборка | полностью (10 профилей) |
| Параметры: ручной ввод, загрузка Excel/CSV и датасета организатора, шаблон, проверка типов и диапазонов, подсказки | полностью |
| Каталог: 189 решений, иерархия, фильтр, поиск, сортировка, источник и подтверждённость каждой ТТХ | полностью |
| Подбор: 8 правил, вердикт с причиной, недостающие данные, объяснимый рейтинг, ручное добавление исключённых | полностью |
| Сравнение до 5 решений по единым ТТХ и экономике | полностью |
| Экономика: парк, CAPEX и OPEX по статьям, эффект, амортизация, окупаемость, ROI, TCO, 3 сценария, трассировка формул | полностью |
| Изменение допущений с фиксацией, what-if, чувствительность к 3 параметрам, рекомендация по интервалам с рисками | полностью |
| 2D-имитация: зоны, маршруты, точки операций, зарядка; пуск, пауза, перезапуск, скорость, выбор сценария, KPI в реальном времени, экспорт PNG | полностью |
| Отчёт PDF и Excel с параметрами, подбором, формулами, допущениями, рисками, датой и версиями | полностью |
| Роли гость / пользователь / администратор, проекты (создание, копия, удаление), сценарии, воспроизведение расчёта с версиями | полностью |
| Администрирование каталога и нормативов | полностью (формы); массовый импорт — через ETL |
| Автоматическое обновление каталога с сайтов по расписанию | не реализовано (ручной ETL) |
| Лизинг и кредит, дополнительный доход в эффекте | план |
| Интеграции с WMS, ERP, 1С, мониторингом | описаны в архитектуре, прототип — импорт параметров из файла |

Результат платформы — предварительная оценка. Он требует верификации при обследовании объекта.
