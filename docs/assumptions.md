# Реестр допущений

Все допущения доступны в интерфейсе (шаг «Экономика» → «Допущения модели»), в API (`assumptions` в ответе `/api/evaluate`) и в отчёте (лист «Допущения»). Пользователь меняет их для своего расчёта, администратор — значения по умолчанию.

| Ключ | Значение | Обоснование | Влияние |

## Допущения по данным (пояснения к ТЗ, п. 5–6)

- Цены каталога — с НДС, без доставки, пусконаладки и глубокой интеграции; эти статьи добавлены в CAPEX долями.
- Дубли строк каталога (один id, разные сценарии) — одно решение со списком сценариев.
- Ровность пола, уровень шума и мощность зарядной инфраструктуры объекта считаются достаточными для выбранных решений. Риски по ним выводятся в блоке «Риски», если датасет задаёт ограничение.
- Если ТТХ нет в паспорте, берётся типовое значение подтипа, и решение помечается как требующее проверки.
